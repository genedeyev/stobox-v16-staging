Stobox Intelligence Graph · MCP server

Give your AI a tokenization fact-checker it can call.

Stobox runs a public Model Context Protocol server. Add it to Claude, Cursor, ChatGPT or any compliant client and your assistant gains six tools over Stobox's tokenization knowledge: search with source links, term lookup, related topics, answer context, a handoff to a person, and a fact check that returns a verdict, the rules a claim breaks, and a correction for each one.

Connect it

This server has no interface of its own. It adds tools to an AI client you already use.

Pick your client, paste one line, then send the test message underneath. Installation is not finished when the connector appears in a list. It is finished when the server says contradicted.

Settings, then Connectors, then Add custom connector. Leave the OAuth client ID and secret empty under advanced settings.

Endpoint URL

https://mcp.stobox.io/mcp

Add this to your MCP config, then restart the app.

MCP configuration

{
  "mcpServers": {
    "stobox": { "url": "https://mcp.stobox.io/mcp" }
  }
}

Run this in a terminal.

Terminal

claude mcp add --transport http stobox https://mcp.stobox.io/mcp

Add an HTTP MCP connector pointing at this URL.

The six tools

What your assistant gains.

Five read. The sixth passes you to a person, and it is listed here with the others rather than tucked away at the bottom.

  1. stobox_knowledge_searchPassages from the graph, each with a source link.When the assistant needs sourced material on tokenization rather than its own recollection.
  2. stobox_term_lookupOne term, defined.When a word has to mean exactly one thing for the rest of the answer.
  3. stobox_related_topicsThe topics the graph connects to the one you asked about.When the question is broader than the term that was typed.
  4. stobox_answer_contextAn answer-shaped bundle: the terms, the sources and the rules that apply.Before drafting anything that has to stay inside what is actually known.
  5. stobox_fact_checkA verdict, the rules a claim breaks, and a correction for each one.When a claim about tokenization is about to be repeated in front of somebody.
  6. stobox_start_tokenizationYour question, routed to a Stobox specialist.When the answer needs a person. It asks for your email and consent first.

None of them touch your account, your files or your data, and none of them write anywhere.

What it will not do

Four things this server is not.

Stated here rather than discovered later, because the value of the rest of this page depends on it.

  • It does not count

    No market data, no asset counts, no prices. Ask it what a rule means, not what something is worth.

  • It cannot see your account

    There is no account to see. It reads nothing of yours and holds nothing between calls.

  • Only tools, for now

    The prompts and resources capabilities are empty. A client that only reads those will find nothing.

  • It is not advice

    Reference material about tokenization, not legal, tax or investment advice, and not a substitute for counsel.

The sixth tool

It hands you to a person, and we would rather say so.

Most reference servers pretend they have no commercial motive. This one has five tools that read and one, stobox_start_tokenization, that puts a specialist in front of you. Naming it out loud costs us nothing we were not going to be told anyway.

What leaves your chat

  • The asset type and the jurisdiction
  • The company, if you named one
  • The notes you already gave your assistant
  • Your email, which it asks for rather than invents

What it will not do

It will not send anything without your consent in the same turn, and it will not guess an address to send it to. If you do not answer, nothing leaves.

The other five tools work whether or not you ever call this one.

If it did not work

Five ways this goes wrong.

In the order we actually see them.

You connected it before 28 July 2026

The handshake changed on that date. A connector added before it will look present and answer nothing. Remove it and add it again with the endpoint above; there is nothing else to migrate.

The client is asking you to sign in

The free tier has no authentication at all. If a sign-in screen appears, the client has been pointed at an OAuth integration rather than a custom connector. Go back and add it as a custom connector with a plain URL.

The assistant answers from memory instead

A connected tool is offered, not forced. Name it in the first message, as the test line above does. After one successful call most clients reach for it on their own.

There is no custom connector option

Then the client, or the plan you are signed into, does not offer remote MCP servers yet, and no setting will change that. Claude Code and a desktop client that reads a config file both work today.

It worked, then stopped

You reached the limit. Community is twenty calls a day and resets. A registered token raises it to five hundred a month and takes one email.
