# Stobox V16 · staging preview

One build of the V16 site, for review. Not the live site and not indexable:
every page carries `noindex,nofollow` and `robots.txt` disallows everything.

Absolute paths are rewritten to the `/stobox-v16-staging/` subpath that GitHub
Pages serves a project site from, so this build only works here.

The live site is https://www.stobox.io/ and nothing here affects it.
Source and builders live in the private repo `genedeyev/stobox-v16`.
